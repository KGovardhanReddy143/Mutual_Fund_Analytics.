# Bluestock Mutual Fund Analytics Capstone

## Project Overview

This project analyzes mutual fund performance, investor behavior, fund allocation, and market trends using Python, SQL, SQLite, and Power BI.

The project includes data cleaning, exploratory data analysis (EDA), performance analytics, advanced analytics, and interactive dashboard development.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Plotly
* SQL
* SQLite
* Power BI
* Git & GitHub

## Key Findings

* SIP participation increased steadily over time.
* Large-cap funds attracted significant investments.
* Equity-oriented funds showed strong long-term growth.
* Investment activity expanded across multiple states and city tiers.
* Risk and return exhibit a strong relationship across schemes.
